# Project Home

Home is the project entry surface: it creates a thread from the landing Composer
and resumes server-owned Continue, Favorite, and Recent chats. It owns Home
screen composition and feed presentation; project-shell routing remains in the
parent feature.

Read [`.context/CONTEXT.md`](.context/CONTEXT.md) before changing its client
boundary, first-send reconciliation, feed behavior, or row geometry.
